Frequently Answered Questions

Everything you need to know

What Java versions are supported? +
Scholaris compiles and runs out of the box on JDK 17, 21, and 25 LTS. Because it uses only the standard library (com.sun.net.httpserver and java.nio), there is zero setup required.
How is data stored and persisted? +
Data is persistently mirrored after each mutation to JSON data files in backend/data/*.json via the generic, thread-safe FileStore<T> engine.
Can I generate printable ID cards? +
Yes! The Digital ID Card Studio includes full 3D card preview, real-time dynamic QR code generation, barcode simulation, and a 1-click printable PDF / image export mode.
How does attendance tracking flag defaulters? +
The registrar console automatically computes attendance standing per student. Anyone with less than 75% attendance is visually flagged in red with a 1-click warning notice generator.
